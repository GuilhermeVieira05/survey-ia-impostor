# Log de desvios em relação ao protocolo

> Alimentar **durante** a coleta, na hora em que acontecer. Vira a "página de desvios" da entrega de 27/Nov.
> Um desvio é qualquer diferença entre o que o protocolo (entregue em 13/Nov) previa e o que foi feito.

| # | Data | Seção do protocolo | O que estava previsto | O que foi feito | Motivo | Impacto na validade | Quem registrou |
|---|---|---|---|---|---|---|---|
| | | | | | | | |

## Situações comuns a registrar

- Mudou meta de respostas, prazo de coleta ou critério de elegibilidade.
- Mudou texto/ordem/opções de uma pergunta depois do início da coleta (evitar; se inevitável, registrar versão).
- Canal de divulgação previsto que não foi usado, ou canal novo que foi adicionado.
- Respostas descartadas (quantas e por qual critério).
- Qualquer mudança no plano de análise (teste trocado, corte de grupos).
- Problemas técnicos no formulário (indisponibilidade, bug de lógica).
